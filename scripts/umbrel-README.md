`hooks/pre-start` im Store laedt sie per Tag `umbrel-<version>` von nrzGit.

| Datei | Inhalt |
|-------|--------|
| `nrzdashboard-amd64.gz`, `nrzdashboard-arm64.gz` | Server (Linux, glibc) |
| `public.tar.gz` | Weboberflaeche (WASM, CSS) |
| `SHA256SUMS` | Pruefsummen |
